# 我的音乐品味

## 生活哲思
- 音乐是灵魂的语言，不需要翻译。
- 好的音乐不是被听见的，是被感受到的。
- 深夜和音乐，是这个时代最后的诚实。
- 我们听的不是歌，是自己。
- 生活很吵，但音乐很安静。
- 有时候沉默比音符更有力量。
